Cada objeto valioso,
bajo control.

ItemGuard escribe un id único en cada objeto que te importa, guarda un registro de dónde está, e impide que tolvas, griefers y accidentes se lo lleven. Cuando algo sale mal, el verdadero dueño puede demostrarlo y recuperarlo.

Empezar Ver los comandos
consola del servidor

Template "Sword" created from diamond_sword

  explosion-protected=true  recoverable=true

> /ig reclaim

  2 of 3 attempts left this window

Qué hace

Cada objeto rastreado lleva un id en su NBT y un registro de dónde está, así que ItemGuard puede encontrarlo, recuperarlo o reconstruirlo más tarde. Los objetos sellados se niegan a soltarse, a ser recogidos por desconocidos, a caer en una tolva, a ser minados o a ser destruidos por una explosión. Nunca suelta objetos al suelo ni los duplica.

Ideas centrales

Seis conceptos cubren todo lo que hace el plugin.

Plantillas

Una plantilla nombra un grupo de objetos y lleva las flags que comparten. Todos las heredan; cada una puede anular cualquier flag de forma individual.

Plantillas →

Flags

Siete interruptores de comportamiento con valores por defecto prudentes: soltar, recoger, mover, tolva, romper, explosión y recuperación.

Flags →

Sellos y reclamo

Un objeto caído al suelo recibe un asiento de bedrock y una etiqueta flotante. Su dueño lo recupera con /ig reclaim — demostrado, limitado, registrado.

Sellos →

Pantallas en el juego

Cada objeto tiene su ficha en pantalla: su estado, su dueño, dónde se vio por última vez, sus flags y todo su historial.

Las pantallas →

Una base de datos por servidor

SQLite de serie, MySQL o PostgreSQL cuando un archivo se queda corto. Comprobado en el arranque para que dos servidores nunca actúen sobre el mundo equivocado.

Base de datos →

Nueve idiomas

Cada mensaje es editable en su propio archivo con los marcadores documentados, y las claves que añade una versión nueva siguen funcionando tras actualizar.

Traducciones →

Requisitos

Paper 1.21+ y Java 21. Eso es todo — los drivers de base de datos van dentro del jar, y LuckPerms y SmartSpawner son opcionales, nunca obligatorios.
